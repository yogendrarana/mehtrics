# Installation Guide

Mehtrics is designed to be easy to install and self-host. You can use our automated installer or set it up manually with Docker.

## Automated Installer

The easiest way to get Mehtrics running is using our installation script. This script will:
- Detect your OS
- Install Docker and Docker Compose (if missing)
- Pull the latest Mehtrics images
- Generate a secure `.env` file
- Start the services

Run the following command in your terminal:

```bash
curl -fsSL https://mehtrics.io/install.sh | bash
```

## Manual Installation

If you prefer to set up Mehtrics manually, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yogendrarana/mehtrics.git
   cd mehtrics
   ```

2. **Configure environment variables:**
   Copy the example environment file and fill in your secrets.
   ```bash
   cp .env.example .env
   ```

3. **Start services with Docker Compose:**
   ```bash
   docker compose -f docker/docker-compose.yml up -d
   ```

4. **Run database migrations:**
   ```bash
   bun run db:migrate
   ```

5. **Access the dashboard:**
   Open `http://localhost:3001` in your browser. The first time you visit, you will be redirected to the `/setup` page to create your admin account.
