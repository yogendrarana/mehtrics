# Self-Hosting Guide

Mehtrics is built to be self-hosted on any Linux VPS with Docker. We recommend a minimum of 1GB RAM and 1 CPU for small to medium workloads.

## Prerequisites
- Docker (20.10+)
- Docker Compose (2.0+)
- A domain or subdomain pointing to your server's IP
- (Optional but recommended) A reverse proxy like Nginx or Caddy for SSL

## Deployment

1. **Clone the repository**
   ```bash
   git clone https://github.com/yogendrarana/mehtrics.git
   cd mehtrics
   ```

2. **Configure Environment**
   Edit the `.env` file generated by the installer or create from `.env.example`.
   Ensure `BETTER_AUTH_SECRET` is a 32+ character random string.

3. **Start the Containers**
   ```bash
   docker compose -f docker/docker-compose.yml up -d
   ```

4. **Verify Health**
   Navigate to `https://your-domain/api/health` to ensure all services (Postgres, Redis, App) are healthy.

## Performance Tuning

### Batch Size
Adjust `BATCH_SIZE` in the worker configuration if you have extremely high traffic. The default is 500 events per insert.

### Memory
Redis is used for ingestion buffering. If you have millions of events in the queue, ensure your server has enough RAM for Redis.

## Backups
We recommend backing up the `docker/postgres-data` volume regularly.
```bash
docker exec mehtrics-postgres pg_dumpall -U mehtrics > backup.sql
```
